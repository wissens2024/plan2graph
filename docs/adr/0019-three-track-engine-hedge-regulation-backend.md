# ADR-0019: 3-트랙 엔진 헤지 + 규제-피드백 공통 뒤단 (벡터-first 단독 폐기)

Status: Accepted
Date: 2026-06-17
Deciders: wissens2024, Claude

## Relates / Supersedes
- **ADR-0006(ONE 소버린 엔진)의 "엔진=소버린 핵심" 프레임 재정의**: 엔진 = *교체가능 아이디어 생성기*, 소버린 핵심 = **규제검증+솔버 뒤단**.
- ADR-0012(생성타깃 wall-cycle) 보강: 벡터 직접생성(diffusion/AR) 단독은 천장 → 헤지로.
- ADR-0013/0018(도메인·프로파일)·0014(Phase) 유지. [[commercial-is-solver-not-generative]] 정합.

## Context
- 3주+ (2026-06-17 8실험 포함) 벡터 직접생성 전수 실패: 코너 diffusion = 중앙붕괴·corner-only 천장(손실 4종·벽 4종 소진, 30k 장기학습 *악화*), 트랜스포머 토큰AR = clean 17%·겹침 0.47. 집계·정렬 통계는 GT 도달해도 **닫힌 방 구조를 구성상 보장 못 함** → 헤일로·불완전. `[검증: diag_structure.py·docs/runs/*]`
- 사용자 통찰: ① 생성형 AI = *아이디어*(레이아웃) ② 정밀·문법·규제·축척 = 우리 솔버. 벡터-first가 어려웠던 건 *생성에 솔버 일(CAD정밀)까지* 시켜서.
- 규제 피드백(채광·면적·인접·동선)은 **코헤런트한 도면**을 전제 → 깨진 벡터엔진 출력엔 적용 불가. **코헤런트 생성기 필요.**
- 한국 데이터 + 규제 DB = **SOTA ≈ 0% 신규성(생성기 무관).** 성공 기준 = "한 방 완벽 도면"이 아니라 **논문 가치 선까지의 산출물.**

## Decision
1. **벡터-first 단독 폐기. 3-트랙 병렬 헤지로 엔진 천장 돌파 시도** (튜닝 재탕 아닌 *진짜 다음 아이디어*):
   - **A · KorPlan-Diff**: **joint 코너+엣지 생성**(엣지 co-생성 헤드 + *생성된* 엣지 따라 정렬). 대안 카드: 이산좌표(HouseDiffusion식).
   - **B · KorPlan-AR**: **닫힘-보장 room-cycle AR** + 제약 디코딩(전역 비겹침·직교 강제).
   - **C · Raster**: 도면 이미지 diffusion → 벡터화 → geomgraph. (64px 검증됨)
2. **공통 뒤단 = 소버린 핵심** (3트랙 공유): 출력 → geomgraph 스키마 → **규제 검증/피드백**(verify→repair→rerank 반복 루프) → 솔버 정밀화(축척·격자스냅·벽두께·DXF).
3. **엔진 = 교체가능 부품. 측정 = 동일 자**: 구조(코너/선·std, `diag_structure`), 도면(방수≈GT·실겹침0·헤일로0), **규제 준수율**. 천장 돌파 = 이 수치 달성.

## Considered Alternatives
1. **벡터-first 단일 계속** — 기각: 3주+오늘로 천장 확정, 추가 튜닝 음(陰)의 수익.
2. **raster 단독 직행** — 기각: 헤지 포기. 벡터가 뚫릴 수도 있고 병렬 비용 낮음. (단 raster가 최우선 확신)
3. **엔진 완성 후 규제** — 기각: 규제(저위험·신규성)를 엔진(고위험)에 인질로. 규제는 생성기 무관이라 분리해 먼저 가치화.

## Consequences
- Positive: 위험 분산(3엔진). 신규성·논문가치를 *생성 성공과 분리*(규제 뒤단). 단계별 산출물 = 논문(L1 규제레이어 → L4 완성). 공통 뒤단 재사용. 벡터-first 실패 = "왜 실패하나" 분석 기여로 논문화.
- Negative: 3트랙 관리·GPU 분배 비용. A/B 돌파 불확실(헤지의 본질).
- Follow-up: **A(joint 코너+엣지)부터 착수.** 공통 벡터화·규제검증 정비. 측정 표준화.
- **★규제 검증 = 국가별 스코프 (2026-06-18 명확화).** 법규(채광/환기 창·면적·대피공간)는 **한국 건축법규**라 창·척도(㎡)가 있는 **한국(KR) 산출물에만 적용**한다. RPLAN(중국, 창·척도 부재)·기타 비-KR 코퍼스는 법규 **N/A → 구조/기하만 평가**(rerank 게이트에서 법규 통과 취급). 구현: `eval_wallcycle_pipeline.py --country`(KR=0일 때만 법규 게이트). 근거: RPLAN은 창문 토큰 0개(`EXPERIMENTS.md §KorPlan-AR`·`DATA.md §5-A`)라 법규를 구조적으로 못 통과 → 비-KR에 법규 게이트 적용은 측정 오류. 규제는 사전학습(구조) 아닌 **한국 단계의 신규성**이라는 ADR 원칙과 정합.

## Assumptions
- [검증] 벡터 직접생성 천장(corner-only·토큰AR). [검증] raster 코헤런트 생성(64px).
- [가정] joint(A)·닫힘보장(B)이 천장을 뚫을 수 있다 — 미검증, 헤지.
- [가정] 규제+한국데이터가 생성품질과 무관히 논문 신규성 확보(SOTA≈0%).
- 목표 불변(한국 규제-인식 벡터 도면) — 방법만 헤지. [[design-canon-readme]] §6 안티플립, [[three-paper-roadmap]].
