# ADR-0014: 목표 2단계 분리 — Phase 1 SCI(다국가 도메인+규제 조건 생성) / Phase 2 상용(하이브리드)

Status: Accepted (Amended 2026-06-15 — novelty 정직화: 규제-인식은 한국 한정, 다국가는 *조건* 생성)
Date: 2026-06-15
Deciders: wissens2024, Claude

## Relates
- ADR-0006(ONE 엔진)·0012(생성 타깃)·0013(다국가 조건 메타)를 *목표/우선순위*로 묶음.
- ADR-0004(렌더 2산출물 — 순수 생성형으로 상용 정밀도 한계 기각)와 일관.

## Context
- **상용급 도면생성은 매우 어렵다** — 반복 실패로 확인. 상용 툴은 순수 생성형이 아니라 **하이브리드(파라메트릭 CAD 솔버 + 규칙)** 방식이라 우리의 3난제(겹침·정렬·축척)가 구조적으로 안 생김([[commercial-is-solver-not-generative]]).
- **한국 데이터는 알바 보정까지 시간이 더 필요** — Corrected 라인 성숙 전.
- 한편 **다국가 도메인 조건(ADR-0013) + 국가별 규제 엔진**은 신규성이 있어 *지금 자산으로* SCI급 논문이 가능.
- → 하나의 "상용급 도면" 목표를 좇으면 계속 실패·재설계. **목표를 둘로 나눠 달성 가능한 Phase 1부터 채운다.**

## Decision
### Phase 1 — 지금 (SCI 목표): "한국형 + 다국가 조건 + 규제-인식 벡터 도면 생성"
- **산출물 수준**: DiffPlanner/GSDiff/FMLM 급 **벡터 레이아웃**(코너·벽·방 폴리곤·문). *완성형 상용 도면(가구·치수·as-built)은 아님* — 그건 Phase 2.
- **신규성(기여)** — 두 기여를 *분리해* 주장(묶어서 "다국가 규제-인식"이라 부르지 않음. Amendment 참조):
  - ① **다국가 도메인 *조건* 생성**(CN/KR/EU, ADR-0013 — RPLAN/CubiCasa **데이터**로 가능, 법규 무관. 플로어플랜에선 문헌상 희소, 잠정 최초).
  - ② **한국 규제-인식 생성**(SOTA는 법규 무지 ≈0% → *한국만으로도* 필드 최초). 우리 한국 법규엔진 175조문+SWRL 보유. **법규 프레임워크는 국가 일반화 가능하나 현재 한국 조문만 보유** — 중국/EU는 미보유(추후 핵심 조문 추가 시 "다국가 규제" 데모 가능, 본 ADR 범위 밖).
  - ③ **한국 데이터셋**(처리·정제).
- **평가**: CAD 품질(ADR-0012: DXF open·wall-loop·overlap·reachability) + 법규 준수율 + 다국가/한국단독 비교 + FID(DiffPlanner 1.23 기준).
- **자산(보유)**: 백본(DiffPlanner)·한국 g-0.4 23k·법규엔진·평가 하니스·조건 설계(ADR-0013)·housing 조건(검증 최강레버).
- **전제(리스크)**: 한국 *기하 생성 품질*이 최소 DiffPlanner급 도달해야 함(현재 비응집 → 40k / wall-cycle 진행 중). 신규성은 *작동하는 생성 위에* 얹힘.

### Phase 2 — 나중 (상용 목표): "완성형 상용 도면, 하이브리드"
- **수준**: 가구·치수·완성도·as-built급 편집 가능 도면.
- **방식**: 순수 생성형 ❌ → **상용식 하이브리드**(생성 + 파라메트릭 CAD 솔버 + 규칙). [[commercial-is-solver-not-generative]].
- **선행**: 알바 보정으로 한국 데이터(Corrected) 품질·양 ↑. 시간 갖고.

### 우선순위
**Phase 1을 먼저 채운다(논문) → 시간 갖고 데이터 보정 → Phase 2(상용) 도전.**

## Amendment (2026-06-15) — novelty 정직화: "다국가 규제-인식"은 과대주장
원안이 ①을 "국가별 규제-인식 생성 … 다국가 프레임워크"로 적어 *다국가 규제 준수*를 암시했으나, **법규엔진 코드 확인 결과 현재 완전히 한국 전용**이다(`rules_legal.RULES`=한국 건축법 조문 하드코딩, `law_api`=국가법령정보센터 law.go.kr 전용, `Rule` dataclass에 country 필드 없음, 임계값=한국값). 따라서:
- **규제-인식 생성**은 **한국 한정**으로 주장한다(그래도 SOTA ≈0%라 *한국만으로도* 필드 최초 — 기여 유지).
- **다국가**는 **도메인 *조건* 생성**(데이터: CN/KR/EU)으로만 주장한다 — 법규와 분리. 둘을 묶어 "다국가 규제-인식"이라 부르지 않는다.
- 법규 프레임워크(채광·환기·피난·최소면적 검사 로직)는 국가 일반화 *가능*하나, 중국/EU **조문·임계값 미보유**. 추후 `Rule`에 country 필드 + 핵심 조문 몇 개 추가하면 "다국가 규제 확장가능"을 데모할 수 있다(여력 시, 본 ADR 범위 밖).
- 결정: **(a) 정직 포지셔닝** = "다국가 도메인 조건 생성 프레임워크 + 한국 규제-인식 생성(첫 사례)". (b) 다국가 규제 데모는 옵션(중국/EU 채광·면적 핵심 조문 최소 추가).

## Considered Alternatives
1. **바로 상용급 도전** — 기각: 매우 어렵고(반복 실패·재설계 고리), 데이터 미성숙, 상용은 하이브리드라 순수 생성으론 도달 난망.
2. **순수 생성형으로 상용** — 기각: 정밀 좌표·치수·편집·법규 정량을 순수 생성이 못 함(ADR-0004 기각이력과 일관). 상용=파라메트릭 솔버.
3. **목표 분리 없이 한 트랙** — 기각: "상용 도면"을 한 목표로 좇다 매 세션 실패·재설계(3주간 반복). 분리가 그 고리를 끊음.

## Consequences
- Positive: *달성 가능한* SCI 목표를 기존 자산으로 확보. 상용은 시간+데이터+하이브리드로 분리해 헛도전 방지. 두 목표가 서로 안 막음.
- Negative: Phase 1도 한국 기하 품질이 발표 수준 도달해야(미확정 — 40k/wall-cycle에 의존). 다국가 데이터 통합·CN/EU 규제 DB는 추가 작업.
- Follow-up(Phase 1): ① 한국 기하 품질 확보(40k 결과 → 필요시 wall-cycle, ADR-0012) ② 다국가 통합 어휘·조건(ADR-0013 follow-up) ③ 규제-인식 생성 루프(rules_legal guidance) ④ 평가(CAD+법규+다국가 비교) ⑤ 문헌 서베이로 신규성 확인 후 투고.

## Amendment 2 (2026-06-15) — Phase1 컨텐츠 범위 확정 + 비교 두 축(데이터 증분)
- **변환/추출(R2G) = 전범위**: APT/DEH/ROW·단일/다세대 전부 그래프화(데이터 풀 최대 확보, 현재 40,495). *변환*은 전범위, *채택*만 제한 — 둘은 다른 층위.
- **Phase1 채택 = Parsed(자동변환) × APT × 현관1 × 방수≤25 × validation통과 = 29,641건.** 인간보정 X. (방수≤25 = [ADR-0011 Amendment].)
- **Phase2 = 동일 R2G + Corrected(인간보정).** 데이터 증분 = **ⓐ 같은 도메인(APT 현관1) 안에서** 보정으로 살린 양·품질. **DEH/ROW·다세대 범위확장 아님**(도메인 고정 — 공정 비교 위해).
- **비교 두 축**(ADR-0009 확장): ① **성능**(Parsed→Corrected, *같은 데이터* = 보정 품질의 가치) ② **데이터 증분**(보정이 살린 *양* = 보정의 또 다른 가치). 두 효과를 분리한다.
- **A/B/C ablation**: **A**=Parsed 29,641 / **B**=Corrected 같은 29,641(양 고정 → 순수 품질, A vs B) / **C**=Corrected + 증분(양 효과, B vs C). 성능 향상이 *품질* 때문인지 *데이터 양* 때문인지 섞이지 않게.

## Assumptions
- `[추론]` 다국가 도메인 *조건* 생성(데이터)과 한국 규제-인식 생성이 *각각* 문헌상 신규(투고 전 서베이로 확인 필요). ※ "다국가 규제-인식"은 미보유 — Amendment 참조.
- `[검증]` 법규엔진은 현재 한국 전용(rules_legal/law_api). 다국가 규제 준수는 본 ADR 범위 밖.
- `[추론]` 한국 기하 생성이 DiffPlanner급(발표 가능) 도달 가능.
- `[검증]` 상용은 하이브리드(파라메트릭 솔버)라 순수 생성과 다른 트랙([[commercial-is-solver-not-generative]]).
- 이 전제가 깨지면(기하 품질 미달/신규성 선점됨) 재검토.
