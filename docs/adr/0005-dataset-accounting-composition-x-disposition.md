# ADR-0005: 데이터셋 회계 = 검수 화면의 「라벨 구성 × 처분」 분류 콤보 (고정 프레임·숫자 이동)

Status: Accepted
Date: 2026-06-11
Deciders: wissens2024

## Context
- 데이터셋의 본질은 **정확한 숫자**다 — 전체 도면 수·세대 수, 그리고 데이터가 **어떻게 구성됐는지**(SPA+STR 둘 다 / SPA만 / STR만 / objocr / 중복 / 비-FP)와 각 구성의 **처분**(사용 / 보정필요 / 제외).
- 그 회계를 보여주는 곳 = **AI-Hub 검수 화면**(T=🏢, G=🧩). **분류 콤보 리스트만 봐도** 데이터 구성이 한눈에 보여야 한다.
- T검수에는 이미 manifest 기반 `AIHUB_LABEL`로 「구성×처분」 콤보가 구현돼 있다(합 = 43,219 도면 / 48,628 세대, 소스 `staging/aihub/manifest.jsonl`). **G검수에는 이 구성 콤보가 없어** 빌드된 부분집합(13,687/27,683)만 처분별로 보인다.
- 지난 10일간 여러 세션이 이 정본 모델을 무시하고 새 카테고리("미변환" 등)·2차 회계를 반복 도입 → 매 세션 비교 불가·동일 재설명 반복. **이게 사용자 최대 고통.**

## Decision
AI-Hub 검수 화면(T·G 공통)의 분류 콤보를 **「라벨 구성 × 처분」의 완전한 숫자 회계**로 통일한다.
1. 카테고리 = **라벨 구성**(dual · 방만 spa_only · 구조만 str_only · objocr · 중복 · 비-FP) × **처분**(✅사용 / 🛠보정필요 / 🚫제외). 각 항목 = **의미 있는 타이틀 + (도면 N · 세대 M)**. 합 = `📋 전체` = **43,219 도면 / 48,628 세대**.
2. 카테고리는 **고정 프레임**이다. 변환·보정이 좋아지면 **숫자가 `보정필요·사유` → 짝인 `사용·사유`로 이동**한다(사유/출처 보존, 보정필요↓·사용↑, **사유별 총량 불변**). 예: `🛠 보정필요·OBJ/OCR만` → objocr 변환 성공 시 → `✅ 사용·OBJ/OCR만→복구`.
3. G검수(🧩)는 T검수(🏢)와 **동일한 콤보 구조·소스 접근**으로 맞춘다 — `AIHUB_LABEL`/manifest 모델, 함수 `aihub_t_status`·`gline_status`·`gline_plan_status`, 세대 규칙 `aihub_fp_units`/`aihub_row_units` 재사용. **재구현·신설 금지.**

## Considered Alternatives
1. **"미변환" 등 새 카테고리 신설** — 변환 안 된 도면(objocr·SPA없음)을 별도 그룹으로 — **기각**: 새 버킷은 고정 프레임을 깨 T↔G·재빌드 간 비교를 불가능하게 만든다. 변환 안 된 것은 별도 그룹이 아니라 **보정필요**(살릴 수 있으니까)이며, 변환되면 사용으로 이동한다. (이 ADR을 쓰게 만든 직접적 반복 실수)
2. **빌드된 그래프만 처분별 집계(현 G검수)** — graphs 폴더만 스캔 — **기각**: 분모(전체 구성)가 빠져 13,687/27,683만 보인다 → "데이터가 어떻게 구성됐는지"를 숫자로 못 말한다. 전체는 43,219/48,628이어야 한다.
3. **G 전용 2차 회계 어휘**(예: `topoedit._plan_cat`의 파일존재 기반 미검수/보정중) — **기각**: 한 화면 두 회계 = 불일치. 정본 함수를 재사용해 한 화면 한 회계여야 한다.

## Consequences
- Positive: 콤보만 봐도 데이터 구성·처분이 정확한 숫자로 드러난다. 변환 개선(objocr·V2V 등)이 `보정필요→사용` 이동으로 **측정**된다. 고정 프레임이라 세션·재빌드를 넘어 **비교 가능**.
- Negative: G검수가 빌드 부분집합이 아닌 **전체 universe(manifest)를 분모**로 잡도록 재작업 필요.
- Follow-up: objocr 변환 성공분은 manifest에서 `(fix, objocr)` → `(use, objocr복구)` 사유로 이동시켜 콤보에 반영. G검수 콤보를 T와 동일 구조로 구현.

## Assumptions
- T 정본 manifest(`staging/aihub/manifest.jsonl`)가 전체 43,219 도면 / 48,628 세대의 (처분·사유·house)를 담는 **단일 소스**다.
- 세대 규칙(사용자 확정): 못 세면 **0**, 제외·중복 = 원본(dup_of) 세대수, 도면 = manifest 행 수.
- 라벨 구성 카테고리(dual/spa_only/str_only/objocr/중복/nonfp)가 데이터셋 구성의 **완전한 분할**(상호배타·합=전체)이다.
