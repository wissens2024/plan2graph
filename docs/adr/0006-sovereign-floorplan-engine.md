# ADR-0006: 한국형 소버린 도면 생성 엔진 — 자체 ONE-엔진(SOTA 기법 부품 조립 + 규제·완전도면 novelty)

Status: Accepted
Date: 2026-06-12
Deciders: wissens2024

## 한 줄 요약
박스 회귀(폐기) 대신, **우리가 소유하는 단일 생성 엔진**을 만든다 — SOTA들의 좋은 *기법*을 부품으로 조립(인용)하고, **우리 novelty = 법규-인식 생성 + 완전도면 + 한국 소버린 도메인**을 얹는다. 모델 3개 직렬 체이닝도, 남의 가중치 단순 파인튜닝도 아니다.

---

## Context (지금까지 측정·검증으로 확정된 사실)

1. **박스 회귀(`geom_gen`/`train_geom`)는 사망했다 — 측정으로 확정.**
   - 방 1개=축정렬 바운딩박스 표현. 실제 방은 폴리곤이라 bbox화하면 겹침.
   - g0 정답(ground-truth) 자체가 **99% 겹침**(0겹침 1%), 정답 렌더도 평균 31건 위반.
   - 겹침억제 손실·데이터 4.6배(g0 8.7k→g1 40k)로도 박스 탈출 실패(겹침 12·19쌍). → **폐기.**

2. **SOTA 4편을 전수 분석·일부 검증했다.** 전부 "벡터 방·벽/문 레이아웃(L3)"에서 멈춤 — **창·가구·실측치수는 아무도 안 만든다**(최신 FMLM 2026 포함).
   - HouseDiffusion(CVPR'23): 방+문 폴리곤 루프, 이산+연속 디노이즈.
   - GSDiff(AAAI'25): 코너+벽 구조그래프, **정렬손실 + 랜덤 자기지도**(연결포인트 정합). 코드 보유(`~/gsdiff_work`).
   - **DiffPlanner('25, FID 1.84)**: 벡터직접(no raster)·경계조건·3단계(노드→인접→분할)·정렬 메커니즘. **코드 보유·검증 완료(FID 1.23 재현, `~/diffplanner_work`).**
   - FMLM('26, 최신): 마크업 문법 + 유효성 제약(constrained decoding), unified conditioning.

3. **법규엔진이 이미 있고 생성 루프에 연결돼 있다.** `rules_legal.py`(채광 §17①·환기 §17②·피난·침실/세대 최소면적, 국가법령 Open API 수집), `gen_loop.verify()`가 integrity+legal+arch 호출→repair. 단 현재 대부분 **위상/필요조건 수준**(정량 준수는 실측 기하 필요).

4. **자산:** RPLAN(글로벌) + 한국 AI-Hub(위상+기하: 문 98%·창 98%·기구 48%) + CubiCasa(기구 보유). `cadrender`(기하→건축스타일 이미지 + DXF, 검증됨).

### 전략적 결정 지점
"DiffPlanner 하나로 충분(옵션1) vs 자체 엔진 개발(옵션3)" 논쟁 끝에:
- **사전학습 엔진을 빌려 쓰면 "남의 것 위에서 무엇을 했다"가 되어 소유·논문 가치가 약하다.**
- **단 "더 좋은 FID"만 노리는 자체 엔진은 트레드밀**(곧 추월)이고 그 자체로 할 수 있는 게 없다.
- → 자체 엔진은 **"FID 동급 + 아무도 안 하는 축(규제·완전·한국)"** 으로 가야 의미·내구성이 있다.

---

## Decision

**우리가 소유하는 단일 도면 생성 엔진(이하 "소버린 엔진")을 개발한다.** 핵심 원칙 셋:

1. **모델은 하나(ONE).** 3개 모델 직렬 체이닝이 아니다(그건 무의미 — 그럴 거면 DiffPlanner 하나가 낫다).
2. **SOTA의 좋은 *기법(부품)* 을 참조·인용해 조립한다.** 모델 통째가 아니라 손실·디노이즈·정렬·유효성 같은 *기법* 단위로 가져온다.
3. **novelty(우리 것) = 법규-인식 생성 + 완전도면 + 한국 소버린.** 논문·제품·주권 가치는 전부 여기서 나온다. 빌린 골격(DiffPlanner)은 인용 base지 contribution이 아니다.

---

## 상세 설계 (엔진 아키텍처)

### 1. 표현 (Representation)
- 도면 = **코너(벽 교차점) 집합 + 벽(코너 간 엣지) + 방 폴리곤(벽 사이클) + 방 종류** (+ 문·창·기구는 완성층에서).
- 좌표: 정규화([-1,1]) 생성 후 **실스케일(mm) 부여**(프로그램 면적/한국 표준 앵커) — 치수·법규 정량화의 전제.
- 참조: GSDiff 구조그래프 · HouseDiffusion 폴리곤 루프.

### 2. 생성기 (단일 conditional diffusion)
- **Transformer 기반 conditional diffusion, 벡터 직접 생성(no rasterization)** — DiffPlanner 골격 참조.
- **조건(입력):** 방 구성(program) + 인접 그래프(위상) + (선택) 경계 폴리곤(=한국 아파트 "틀"). unified conditioning은 FMLM 참조.
- 단계 분해(노드→인접→분할)는 DiffPlanner 참조하되, 통합/단순화 가능성은 P2에서 실험으로 결정.

### 3. 차용 부품 (출처 명시·인용)
| 부품 | 출처 | 역할 |
|---|---|---|
| 벡터직접 diffusion 골격·경계조건 | **DiffPlanner** | 최고 FID base |
| 정렬 손실 + 랜덤 자기지도 | **GSDiff** | 코너/벽 **연결포인트 정합** |
| 이산+연속 디노이즈 | **HouseDiffusion** | 평행·직각·코너공유 기하관계 |
| 유효성 제약(constrained decoding) | **FMLM** | 벽 안 닫힘/겹침 원천 차단 |

### 4. ★ 우리 novelty 부품 (contribution)
1. **규제-인식 생성 (code-compliant generation)** — `rules_legal`(한국 건축법규: 채광·환기·피난·면적)을 **생성 안에서 강제**: diffusion guidance(분류기/규칙 가이드) 또는 손실 패널티 또는 후처리 보정 루프. **필드 최초**(SOTA는 법규 무지).
2. **완전 출력 (complete drawing)** — 레이아웃 위에:
   - **문**: 위상 공유벽에 배치(or 생성).
   - **창**: 외벽 규칙/학습(AI-Hub 창 데이터 98% 활용).
   - **기구**: 방종류별 규칙 or **CubiCasa 블록 검색**.
   - **치수**: 실스케일 → `cadrender`가 계산.
3. **한국 소버린 도메인** — 한국 AI-Hub 파인튜닝(현관 동선·발코니확장·전실·한국 방 비율). 중국형(RPLAN)과 구별되는 주권 모델.

### 5. 학습 (전이학습 + 콤보 비교)
- **사전학습:** 글로벌(RPLAN; 선택적 +CubiCasa) → 강한 레이아웃 base.
- **파인튜닝:** 한국 AI-Hub → 한국 도메인.
- **콤보 매트릭스(측정용):** 사전학습{글로벌 / 없음} × 파인튜닝{한국 / 없음}. (없음×없음=미학습 제외.) **다중 시드 + 수렴**(과거 음의 전이는 단일시드 노이즈였음).
- "사전학습이 도움 되나?"를 가정 않고 **측정**으로 판정.

### 6. 보정 루프 (neuro-symbolic, 생성 후)
`생성 → verify(기하 R1~R8 + 법규 rules_legal + 완성도) → 교정(연결포인트 스냅·법규 위반 수정·기구 방안 clamp·문/창 벽 스냅) → 재검증/재생성` 반복. `gen_loop`·`cadrender.autocorrect`·`rules_legal` 확장.

### 7. 출력
`cadrender` → ① 건축스타일 이미지(벽·문·창·기구·실명·치수) + ② **AutoCAD DXF**(레이어 분리).

## 데이터 갭 → "있는 데이터로 의미적 추론" 해서 채움 (neuro-symbolic)

**측정된 데이터 채움률(2026-06-12, 300개):** 방폴리곤 100% · 문 97% · 창 96% · **문스윙방향 57%** · **위치기구 0%** · **축척(scale_mm_per_px) 0%**.
→ 레이아웃(폴리곤·벽·문·창)은 충분. **결정적 갭 = 축척·기구(둘 다 0%), 부분 갭 = 문 방향(57%).**

**원칙: 갭은 *별도 데이터 수집*이 아니라, *이미 있는 데이터(역할·문폭·폴리곤·인접)로 의미적으로 추론*해서 채운다.** 데이터 갭은 블로커가 아니라 우리 neuro-symbolic 층이 메운다(= ADR-0006 novelty 그 자체).

| 갭 | 있는 데이터 | 의미적 추론으로 채움 |
|---|---|---|
| **축척(mm/px)** | 문 폭(px, 97%) / 방 폴리곤 / 프로그램 면적 | **문 폭 ≈ 800~900mm 앵커** → `scale = 900 / 문폭px`. (대안: 목표면적 √, 표준 방크기 제약) |
| **기구(가구)** | 방 역할(100%) / 방 폴리곤 / 문 위치 | **역할→기구 카탈로그 + 배치 제약**: 침실→침대(문 반대 긴벽), 거실→소파+TV(마주봄), 주방→레인지+싱크(일렬 벽), 화장실→변기+세면(벽), 현관→신발장. |
| **문 방향(나머지 43%)** | 인접 두 방 / 문 위치 / 벽 | 사적공간은 안쪽으로, 동선 방향으로 추론. 끝까지 모호한 것만 **알바 SVG 보정**(좁은 타깃). |

**법규 정량의 scale 종속성(중요):**
- **채광·환기 면적비(1/10·1/20) = scale-invariant(비율)** → **절대 축척 없이도 검증 가능.**
- **침실/세대 최소 면적(㎡)만** 절대 축척 필요 → 위 문폭 앵커로 해결.

**채운 뒤 자동 보정 루프**(§6)가 겹침·통로 막힘·문 벽이탈·기구 방밖·법규 위반을 검출→교정→재배치한다.

**정직한 한계:** 규칙 기구 배치·축척 추정은 **"표준에 맞는 그럴듯함"** 이지 *as-built 정확*은 아니다(모든 AI 도구가 추정·검증 필요). 목표(쓸 만한 도면 + 법규 통과)엔 충분.

## 평가 (검증 기준)
1. **FID/KID (RPLAN)** — 우리 엔진 변형마다 측정, **DiffPlanner 베이스라인 FID 1.23과 비교.** 하니스 보유(`pytorch-fid`/`clean-fid`, 12,002 테스트셋).
2. **법규 준수율** — `rules_legal`로 생성물 채점(SOTA ≈ 0%).
3. **완성도** — 문·창·기구·치수 충족 비율.
4. **한국 도면 품질** — 실측/전문가 비교.

**성공 기준:** `FID ≤ DiffPlanner 동급(약 1.2~1.5)` **AND** `법규준수·완성도에서 SOTA 압도`. (FID만으로 이기는 건 천장·트레드밀이라 목표 아님 — "동급 레이아웃 + 유일한 준수·완전"이 포지션.)

## Considered Alternatives (기각)
1. **박스 회귀(`geom_gen`)** — 측정으로 사망(정답 99% 겹침). **폐기.**
2. **모델 3개 직렬 체이닝** — 같은 일을 하는 생성기를 직렬로 못 탄다. 무의미. **기각.**
3. **DiffPlanner 가중치 단순 파인튜닝만** — 소유·novelty 약함("남의 것 위에서"). **기각**(단 사전학습 init로 활용은 가능).
4. **3개 SOTA 앙상블** — 생성모델은 출력을 평균/병합 불가. **기각.**
5. **"더 좋은 FID"만 노리는 자체 엔진** — DiffPlanner ~1.2는 천장, 곧 추월(트레드밀). 그 자체로 효용 없음. **기각**(→ 규제·완전·한국 축으로 전환).

## Consequences
- **Positive:** 우리 소유 엔진(빌린 base가 아닌 우리 설계) · 한국 소버린 · 추월 안 당하는 축(규제·완전) · 논문 A(한국 데이터셋)·B(완전도면)·C(법규 준수)·D(엔진 method)의 토대.
- **Negative:** 수개월·고난도 ML. diffusion 재구현/결합은 재현성 갭 위험. novelty가 thin해질 위험(→ 규제·완전 부품이 substantive해야 함).
- **헤지:** **옵션 1(DiffPlanner)을 병렬로** 굴려 *작동 파이프라인 + 비교 베이스라인 + 제품*을 먼저 확보. 소버린 엔진(P2 구현)이 이걸 막지 않게 한다.

---

## Roadmap (단계)
- **P0 소스 분석 완비:** GSDiff·DiffPlanner 보유·분석 완료. HouseDiffusion 클론·분석 추가, FMLM 코드 확인.
- **P1 설계 확정:** 본 ADR.
- **P2 구현:** DiffPlanner 골격 + 차용 부품(GSDiff/HouseDiffusion/FMLM) + 우리 부품(규제·완전).
- **P3 학습·평가:** 사전학습(글로벌)→파인튜닝(한국)+콤보비교 → FID + 준수 + 완성 평가.
- **병렬 트랙(옵션1):** DiffPlanner로 한국 파인튜닝 + cadrender DXF = 제품·베이스라인. P2가 막히면 이쪽으로 가치 산출.

---

## Assumptions / Risks (정직)
- 빌린 기법 결합 + 우리 부품이 **FID 동급 이상**을 낼 것(불확실 — P3에서 측정으로 검증, 안 되면 옵션1로 폴백).
- 법규 정량 준수는 **실측 스케일·좋은 기하**가 전제(레이아웃 품질에 종속).
- 한국 복잡벽(발코니확장·전실)은 GSDiff 논문도 "어렵다"고 명시 — 데이터→코너+벽 변환이 난관.
