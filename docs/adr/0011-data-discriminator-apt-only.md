# ADR-0011: 데이터 구분자 — 자동 "사용"은 APT 정형 단일세대만, 나머지는 사람 판단

Status: Accepted
Date: 2026-06-14
Deciders: wissens2024, Claude

## Relates
- ADR-0005(데이터 회계 구성×처분)을 *처분 기준*에서 구체화.
- ADR-0008/0009(Parsed/Corrected) 위에서, "사용/보정필요/제외" 판정 규칙을 명시.

## Context
AI-Hub는 **APT·단독(DEH)·연립(ROW)** 이 섞이고, 같은 APT 안에도 정형(현관1·정상 방수)과 비정형(현관 2개=병합 다세대, 14방+ =과다/병합)이 섞여 있다. "baseline vs baseline+보정"만으로는 *형태*를 구분 못 해, 비정형이 "사용"에 섞이면 모델이 **"잘못된 한국 아파트"** 를 배운다(현관 2개짜리 단일세대 등). 따라서 데이터셋에 *형태 구분자*가 필요하다 — 단순 처분 2축 위에.

## Decision
1. **자동 "사용" = APT + 정형 + 단일세대(현관 1개)만.** DEH·ROW와 비정형은 자동 사용 안 함 → **사람 보정·판단** 대상.
2. **현관 ≥ 2 또는 방 수 ≥ 14는 변환에 성공해도 "보정필요"** 로 둔다(병합 다세대·과다 의심). (방수 임계 14는 검토값 — 온전 데이터 분포 median 14·p95 17 기준.)
3. **주거형태(house: APT/DEH/ROW)와 정형성 신호를 그래프에 필수 포함** — 학습·필터·평가가 형태별로 갈라 볼 수 있어야 함.
4. **"사용"이어도 보정 중 "제외" 가능**(가역) — 사람이 비정형을 발견하면 내릴 수 있다.

## Considered Alternatives
1. **전체를 자동 사용** — 기각: 비정형(현관2·14방+)이 섞여 모델이 잘못된 한국 아파트 학습.
2. **baseline ± 보정 2축만(형태 구분 없음)** — 기각: APT/DEH/ROW·정형성을 못 갈라 비교가 흐려짐.
3. **DEH/ROW도 자동 사용** — 기각: 한국 소버린 1차 타깃은 APT. DEH/ROW는 사람 판단으로 점진 편입.

## Consequences
- Positive: 깨끗한 한국 APT 정형 코어로 학습(노이즈↓), 나머지는 사람 보정으로 점진 증량. 형태별 평가 가능.
- Negative: 자동 사용 모수가 줄어듦(APT 정형만). DEH/ROW 활용은 사람 손에 의존.
- Follow-up: `dataset_status._corrected_disp`에 APT-only use 규칙 반영 · 그래프 meta에 house/정형성 보장 · 에디터에 "제외" 버튼.

## Assumptions
- APT 정형 단일세대가 한국 소버린 1차 학습에 충분한 양·품질을 준다.
- 현관 수·방 수가 병합 다세대/과다의 신뢰 신호다(현관2=병합, 14방+=과다 의심).
- 임계(14)는 데이터 분포로 재조정 가능 — 깨지면 재검토.
