# Plan2Graph 데이터셋 카드 (v0.1)

- 출처: AI-Hub 건축 도면 데이터(dataSetSn=71465), `C:\dev\workspace\plan2graph`
- 단위: **세대(주거) 단위 방-문-방 위상 그래프**. 각 그래프 = 배치(layout) + 파생 제약(constraints) 한 쌍.
- 좌표: 픽셀. 면적: scale(㎡) 확보분은 ㎡, 미확보분은 픽셀²(치수선 OCR 역산·신뢰게이트).

- 주택유형: APT 5,671, ROW 392, DEH 243
- 세대당 방수: 최소 5, 중앙값 14, 최대 56
- 발코니 통로(미닫이창) 보유 세대: 5,772 (91.5%)
- **scale 확보(㎡ 변환) 세대: 4,073 (64.6%)** — 치수선 OCR 역산, 침실면적 신뢰게이트 통과분. 바닥면적 중앙값 100㎡. 미확보분은 scale=None(scale_quarantine.csv)

## 알려진 한계
- **scale 부분 확보**: 4,073세대 ㎡ 변환(치수선 OCR). 나머지는 픽셀² → 면적 의존 법규는 ㎡ 확보분에만 적용, 나머지는 scale_quarantine.csv.
- **`공간_기타` 노이즈**: 기타가 최다 노드. 벽두께·자투리 단편이 개방통로로 세대에 편입돼 노드 수를 부풀림. 면적 임계 필터 검토 중(DECISIONS_NEEDED).
- **개방통로(open) 임계 민감도**: gap≤60px·미피복비율≥0.30 기준. 드물게 과연결(>60방)은 방수 상한으로 격리. 손검증 20장 정량 측정은 후속.
- **문-방 추론 정확도**: 합성 단위테스트 통과·시각 게이트 확인 단계.
- **다세대 시트 분해**: 한 PNG의 여러 세대를 연결요소로 분해. 드물게 인접 세대가 오결합될 수 있음.
